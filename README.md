\# PLP Python Week 4 - Functions



This assignment demonstrates how Python functions can reduce repeated code and make programs easier to reuse.



\## Files



\- `welcome.py` - Contains a `welcome()` function that creates and returns a greeting for different names.

\- `toolbox.py` - Contains three functions: `double()`, `is\_pass()`, and `greet()`.



\## Hardest Function
